# v0.3.0 implementation plan

Date: 2026-08-28

## Objective

Ship three measured, local-first harness improvements without forking the DSH
agent loop:

1. a content-free efficiency ledger for LLM, tool, retry, compaction and turn
   metrics;
2. per-tool output budgets that use DSH's official spill-store seam to retain
   full oversized text while showing the model a bounded preview;
3. stable capability profiles generated from the exact shipped Standard, Code
   and Minimal presets, selected between sessions rather than changing the tool
   set during a session.

## Boundaries

- Target and pin `@deepseek-ai/dsh@0.1.1-rc.2`.
- Do not read, rewrite, remove or publish provider/GitHub credentials.
- Keep telemetry local and append-only. Never record prompt text, message text,
  tool arguments, tool results, environment variables or workspace paths.
- Preserve a tool's canonical value. Output budgeting may replace only its
  model-facing text and the durable Code Mode dispatch copy.
- Reuse `ctx.spillStore`; keep DSH's existing 50 kB generic spill policy as a
  fallback instead of replacing its storage implementation.
- Generate profiles from shipped source directories with exact-anchor checks;
  fail on incompatible upstream layouts.

## Planned changes

- `src/efficiency-ledger.js`: local JSONL writer, safe metric projections,
  `llm/stream`, `tools/execute`, agent and session observers, summary helper.
- `src/output-budget.js`: per-tool caps, UTF-8-safe official `TextRetainer`,
  official spill-store calls and deterministic recovery notices.
- `src/capability-profiles.js`: immutable Standard/Code/Minimal profile table.
- `cordis.patch.yml`: load SkillOpt, the ledger and output budgeting as stable
  host rows.
- preset/install/doctor/CLI changes: generate and validate all three profiles,
  expose `dsh-kit metrics`, and report artifact locations.
- tests: pure policy tests, listener integration tests, three-profile generator
  tests, installer/config/public-package checks.

## Acceptance criteria

- All existing tests still pass and new failure paths are covered.
- An oversized plain-text result saves the complete text and emits a replacement
  within the selected byte budget; storage failure leaves the original result.
- A ledger file contains numeric/enum metadata but none of the secret fixture
  prompt, arguments, result text or workspace path.
- Standard, Code and Minimal generated presets are ownership-marked and preserve
  the upstream source hash; repeated generation creates a backup.
- `npm run check` and `npm pack --dry-run` pass on the working machine, followed
  by a clean public-repository scan.
- The final commit is pushed to the configured public GitHub origin and the
  remote commit is verified.
